# YouTube 演示视频候选方向

此清单只帮助人工挑选，不表示这些频道的每条视频都有完整原生时间戳字幕。最终素材须逐条用字幕获取链路验证。

| 方向 | 可搜索的频道 | 为什么适合验证语义时间轴 |
| --- | --- | --- |
| 中文科技产品评测／拆解 | [极客湾 Geekerwan](https://www.youtube.com/@geekerwan1024) | 参数、测试、结论在不同段落出现，适合观察信号随讲解阶段改变。 |
| 英文产品评测 | [Marques Brownlee / MKBHD](https://www.youtube.com/@mkbhd) | 产品介绍、具体体验与评价交替出现，便于点击高峰回到原话。 |
| 中文商业故事／知识讲解 | [小Lin说](https://www.youtube.com/@xiao_lin_shuo) | 连续叙述中通常有背景、机制、例子等不同信息密度。 |
| 英文教程 | [freeCodeCamp.org](https://www.youtube.com/@freecodecamp) | 可寻找操作步骤明确、时长适中的课程；避免首轮选择数小时长课。 |
| 英文娱乐访谈 | [First We Feast / Hot Ones](https://www.youtube.com/@firstwefeast) | 提问、回答与轻松互动交替，适合测试事件类信号。 |
| 深度访谈备选 | [Lex Fridman Podcast](https://lexfridman.com/podcast/) | 话题和追问丰富；首轮应选时长可控的片段，避免过长视频增加分析费用和等待。 |

筛选时优先选约 10–30 分钟、讲话密集、原生字幕覆盖完整、含义切换明显的视频；跳过直播、音乐／画面主导、字幕缺口大或无法稳定跳转的条目。三条最终视频可以跨三种方向，也可以选能清楚展示不同信号分布的其他组合。上台前对每条视频分别检查自动排序最高的两个热点。
