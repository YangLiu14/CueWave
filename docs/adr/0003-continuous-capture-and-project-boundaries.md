# 持续采集与可修正的项目边界

现场演示从用户点击开始后持续使用 MacBook 内置麦克风，跨多个项目 pitch 保留一条完整时间轴，直到用户主动停止。CueWave 根据静音和说话内容推测项目边界：证据充分时自动切分，不确定时显示候选边界；用户始终可以手动切换、合并或拆分项目段。保留总时间轴和原始字幕，是为了在自动切分出错时能修正归属，不丢失边界附近的内容。YouTube 演示阶段不启动麦克风。

新项目段默认使用序号命名；从讲话提取的项目名仅作为建议。点击“新项目”时在当前时刻建立边界，之后可拖动修正。跨越项目边界的读数重新计算，期间明确显示处理中。所有项目段默认继承同一套探针配置，但可单独调整。现场讲话以中文为主，另有一位英文发言者。

同一场次自动识别中文与英文，无需操作者手动切换语言模式。

同一项目的问答归属当前项目；主持人串场等过渡内容归入“间场”，新 pitch 开始才划入下一个项目段。
