# 含糊探头先明确含义

每个探针词在进入分析前先检查是否有歧义。有歧义时，CueWave 使用 Gemini API 模型生成含义明确的备选描述，由用户选择，再据此形成交给 Jev 的判断标准。用户可以查看简短标准与正反例；定义变更产生新版本，旧读数保留原定义。这个决策避免系统暗中替用户选择判断对象，也避免同名探针的读数在不同含义之间混用。无需在本轮决定各视频类型和项目 pitch 的具体探针内容。

歧义检查结果按探针定义缓存；切换视频或项目时不重复检查。若备选描述都不符合意图，用户可以改写，改写后的输入再次由 Gemini 检查。

Gemini 临场不可用时，已确认并缓存的探针继续运行；新探针显示歧义检查失败并允许重试，不跳过含义确认。
